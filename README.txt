STITCH BONUS CALCULATOR — HOW TO RUN AS APP
============================================

Opening index.html in a browser tab is NOT app mode.
Use one of these methods:

METHOD 1 — EASIEST (recommended)
--------------------------------
1. Double-click:  Launch App.bat
   → Opens in its own window (no browser tabs/address bar)

METHOD 2 — DESKTOP SHORTCUT
---------------------------
1. Double-click:  Install App.bat  (one time only)
2. Use desktop icon:  Stitch Bonus Calculator

METHOD 3 — INSTALL IN WINDOWS (Chrome / Edge)
---------------------------------------------
1. Run Launch App.bat first
2. In the app window, click "Install to Device"
   OR menu (⋮) → Apps → Install Stitch Bonus Calculator

METHOD 4 — DOWNLOAD ON ANOTHER PC
---------------------------------
1. Download Stitch-Bonus-Calculator.zip
2. Unzip the folder
3. Double-click Launch App.bat

Files you need:
  Launch App.bat    — starts app every time
  Install App.bat   — creates desktop shortcut
  index.html        — calculator (do not open directly for app mode)
  server.ps1        — local server (runs automatically)
